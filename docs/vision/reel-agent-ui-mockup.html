Agent-side surface · mockup · not a spec

What running the Reel Agent looks like

Two things, honestly separated. What's authorized today is a command line plus a plain-language report and JSON manifests — ADR-001: "no polished review UI in the POC." The desktop review app below is a projection — an addable-later surface, and interface work is a stop-and-ask, not something this project has designed or authorized. It's here so you can picture the Phase-3 review experience, not because it exists.

On the placeholders: clip tiles are abstract on purpose — the pipeline does face detection and counting (the "faces N" chip), never identification, and no media is shown or uploaded. What you'd actually see is your own footage, rendered locally.

Why this is a projection, not a plan

[ADR-001](proposed) keeps the POC to CLI + report/manifest and lists a desktop review app only as an addable-later surface. [ROADMAP.md] marks interface work as stop-and-ask — not a judgment call. This mockup commits the project to nothing; a real review UI would need validated editorial quality first, then its own accepted design.

The system proposes, a human decides — the review surface is where deciding happens, whether that's a report or, one day, this.
