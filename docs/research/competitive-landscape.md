## Answer: does a true solution already exist?

**For automated montage creation — yes, and it is commodity.** Apple Photos Memory Movies and Google Photos Highlight Videos ship this free inside the default camera roll; CapCut AutoCut and GoPro Quik do it free in dedicated apps; AidVid sells it directly. Auto-assembly and beat sync are **materially served**. This project must not be positioned as though generic automated montage creation were unserved — that claim is false and would collapse on first contact with a user who owns an iPhone.

**For explainable editorial judgment — not evidently.** No shipping product verifiably combines multi-clip ingestion, junk filtering, chronology-true event coverage, best-subclip extraction, editorially-motivated beat alignment, and a transparent review/correction loop. Every incumbent output is a montage, not an account of why those clips were chosen.

**Grade: hypothesis, not finding.** This assessment reads vendor documentation, not measured output. Two things must happen before it can be relied on:

1. **EXP-001 fills in the competitive-floor table above** by running the same day of footage through each incumbent and scoring outputs blind against the same rubric used on this system's drafts. If any incumbent scores "would post with minor tweaks," the gap is smaller than assumed and the project framing must be revised before Phase 1 proceeds.
2. **The floor is re-measured at every phase close.** Apple and Google improve this capability each OS cycle at zero acquisition cost. A platform vendor shipping reviewable editorial reels natively is kill criterion 3 — an event to detect early, not discover late.

## Minimum viable experience

Folder input → must-include marking → controls (duration/chronology/audio) → analysis report → **one** auditable draft → lock/remove/restore → regenerate → explicit export. The central value is the draft's editorial judgment and the honesty of its rationale; templates and interface are secondary. One draft, not several: multiple options create decision fatigue and contradict the value proposition.
